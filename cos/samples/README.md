# Sample conversations (synthetic)

These are synthetic test inputs for the "upload a conversation" feature. Chris is the owner; every other person, company and amount is invented. There are no real people and no confidential content.

- `otter-founder-1on1.txt`: a 1:1 between Chris and a founder, in Otter.ai text export format ("Speaker Name  M:SS" header line, text, blank line).
- `granola-partner-sync.md`: a partner meeting, in Granola-style markdown ("# Partner sync" title, "**Me:**" for Chris and "**Them:**" for everyone else).
- `zoom-lp-call.vtt`: an LP call with two people from one LP, in Zoom WebVTT format ("WEBVTT", numbered cues, "00:00:01.020 --> ..." timing lines, "Name: text").
- `plain-hallway.txt`: a hallway chat with a side-project collaborator plus a spouse text read aloud, as plain "Name: text" lines with no timestamps.

Each file mixes 1-2 decisions only Chris can make, 2-3 tasks an agent could do, a line or two a standing rule covers, and noise.
